# Flappy Bird
Its a bird save Game from Obstacles. And We all Know this game very well.
## Description
I built this game using JS, CSS , HTML. Firstly The game has a background of city theme. The bird will be waiting for you to start. After the start it start falling down
and you need to immediately bring it up and soon you will encounter obstacles which you must go through to gain points. If you hit an obstacles the game's over
and you will need to restart it again to play again.
